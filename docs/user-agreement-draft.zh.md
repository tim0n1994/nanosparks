# 用户协议与隐私政策（草案）

> 对应 PRD §8 合规清单：用户协议/隐私 → A4 上线前。
> 本文件为法律文案草案，需专业律师审核后方可正式使用。

## 1. 服务概述

NanoSparks（以下简称"本服务"）是一个播客阅读与内容再创作工具。用户通过粘贴播客链接，获取带说话人标注的文字版、导读、金句，并可生成跨平台图文内容。

## 2. 内容责任

- 用户提交的播客链接须来自公开渠道。用户对所提交内容的合法性负责。
- 本服务生成的文字版仅供个人学习、研究使用。用户不得将全文转写用于商业传播。
- 公开页仅展示导读摘要与短引用，全文需登录后阅读。

## 3. AI 生成内容标识（《人工智能生成合成内容标识办法》2025-09-01）

- 本服务生成的导读、金句、图文包均为 AI 辅助生成内容。
- 导出的图片文件元数据包含 AIGC 隐式标识（服务商编码 + 内容编号）。
- 用户在第三方平台发布本服务生成的内容时，应按各平台规则主动声明"含 AI 合成内容"。
- 用户不得恶意删改、去除 AI 标识。

## 4. 数据用途与共享缓存

- **共享转写缓存**：来自公开来源的播客转写结果进入全局共享缓存，供所有用户只读访问。
- **私有数据**：用户上传的音频文件永不进入共享缓存，仅供用户本人访问。
- 用户的高亮、笔记、阅读进度、图文包等私有数据按用户隔离。
- 缓存命中不消耗用户的免费额度。

## 5. 删除权

- 用户可删除自己的私有数据（高亮、笔记、图文包、阅读进度）。
- 用户上传的音频文件及其转写结果可随时删除。
- 共享缓存中的公开来源内容在 DMCA/版权投诉下架时，将从公开页移除。

## 6. 免责声明

- 本服务不对播客内容的准确性、完整性负责。
- 转写结果可能存在错误，用户应与原始音频核对。
- AI 生成内容可能存在偏差，用户发布前应自行审核。
