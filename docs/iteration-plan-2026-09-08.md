## 本轮架构和模块边界

1. **访问边界**：共享 `requireConversationAccess(id, read|write)`。认证后，本人/管理员可修改；共享缓存只授予阅读权限。私人高亮、进度属于当前用户，不能借此修改共有正文。保留现有登录墙。
2. **安全重试**：先验证权限、配额和可恢复输入，再提交任务；失败请求保留原文和历史产物。区分缓存已就绪、处理中和失败，避免“缓存命中”掩盖失败。成功转写后才替换数据。
3. **队列自愈**：队列连接生命周期属于 worker；每个阶段独立恢复。无法核实队列状态时不得假设空闲；有部分结果不等于完成。只给已证明幂等的阶段启用自动重试，保留有限任务历史。
4. **转写输入**：显式本地路径、持久存储 key、Source 媒体和旧链接进入同一可解释的输入解析通路；FlowProducer 作业不得再重复发起分析。
5. **阅读证据**：在真实 EvidenceSpan 存在时携带话轮/时间深链，加载并定位对应原话；没有音频也能定位文本。首次完成时间保持不变。

五个工作流并行实施，各自拥有不重叠文件；主代理负责跨模块契约、现有工作保护、运行时取证、最终 diff 和整体验证。优先模型 GLM 的加密任务传递不可用，已改用可执行的原生模型继续。

## 验收门禁

- G1：匿名、本人、他人、共享缓存的读写矩阵；拒绝时无任务/数据副作用；生产缺失认证配置不获得开发身份。
- G2：无媒体、队列失败、重复重试、ASR 失败均保留旧内容；合法重试可进入正确队列。
- G3：watchdog 不关闭共享连接；转写/分析独立核查；未知队列状态不恢复；失败入队可再次尝试；隔离 Redis 验证有限重试。
- G4：上传 key、显式 flow 路径、旧媒体路径正确传入转写；flow 不重复分析；替换过程事务一致。
- G5：图/星图证据可落到正确原话，超出首批 200 turns 时可继续加载；重复完读不刷新首次完成日期。
- G6：完整执行 `npm run verify`，逐阶段记录 exit code；验证真实页面并记录运行实例与源代码是否一致。
- G7：指定原始 URL `https://www.youtube.com/watch?v=knx2wrILP1M` 的旧记录可只读核对；真实新处理与 10 链接矩阵若未运行必须明确保留为未验收，不用 mock 代替。
