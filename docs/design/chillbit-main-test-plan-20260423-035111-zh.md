## 关键路径测试（周五凌晨2点发布）

1. **摄取准确性：** 提交5个已知播客节目，验证关键引用出现在可视化中
2. **参考相关性：** 检查20个生成链接，>70%应相关（人工评分）
3. **移动端渲染：** iPhone 12上可视化加载 <3秒
4. **可分享性：** 链接无需登录即可工作，无认证错误
